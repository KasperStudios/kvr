# KVR (Kasper VR / Spatial Visor) — Minecraft Spatial OS & VR Mod

Концептуальный документ и архитектурная спецификация проекта **KVR**.
Мод добавляет в Minecraft систему носимой пространственной дополненной/виртуальной реальности (Spatial Visor / Cyber Glasses) с поддержкой свободно парящих 3D-окон, встроенного JS-движка, магазина скриптов и реактивной интеграции с ComputerCraft: Tweaked и Create.

---

## 1. Ключевая концепция и UX

1. **Носимый девайс (KVR Visor / Cyber Glasses):**
   - Экипируется в слот шлема или специальный аксессуарный слот (Trinkets / Curios).
   - При надевании активирует проекционный пространственный HUD.
   - Слот под периферию: установка **Wireless Modem** / **Ender Modem** из ComputerCraft превращает очки в сетевой узел Rednet.

2. **Модульная сборка очков по частям (Hardware Crafting & Assembly):**
   - Очки не крафтятся банальным одним кликом из 3 слитков. Это настоящий кибер-девайс, собираемый из отдельных модульных компонентов:
     - **Корпус и кастомизация внешнего вида:**
       - `Корпус очков (KVR Chassis / Casing)` — отдельный крафтовый компонент (пластик, медь, андезит или железо), куда монтируются все внутренние платы и линзы.
       - **Покраска корпуса красителями (Dyeing & Custom Colors):**
         - Корпус (или уже готовые очки) можно красить любыми ванильными красителями на верстаке или в котле (по аналогии с кожаной броней через Data Components `dyed_color` / RGB Hex)!
         - Кастомный цвет корпуса динамически отображается на 3D-модели очков на голове персонажа, в руках и в отражении виртуального зеркала.
       - `Эластичный ремешок / Оголовье` (кожа, нити, резина/слизь) — фиксация на голове игрока.
       - `Оптические линзы x2` (тонированное/очищенное стекло, аметистовые осколки, редстоун-напыление).
     - **Электронная начинка (Внутренние слоты шасси):**
       - `CPU (Центральный процессор)` — определяет лимит запущенных приложений и частоту тиков QuickJS.
       - `GPU (Видеочип)` — отвечает за максимальное разрешение окон, 3D-зеркало и сглаживание интерфейса.
       - `RAM (Оперативная память)` — модули ОЗУ (лимит памяти под переменные и тяжелые скрипты).
       - `Storage Disk (Накопитель / SSD / Флеш-чип)` — размер VFS под файлы, музыку и пакеты `.vrapp`.
       - `Power Management Unit / Блок питания`.
       - `Аккумуляторная батарея (Battery Pack)` — емкость в FE/RF энергии (очки требуют зарядки!).

3. **Энергия, влияние железа на систему и апгрейды (Hardware Bottlenecks & Upgrades):**
   - **Философия современного Hi-Tech дизайна:**
     - Мод KVR посвящен передовым современным технологиям. Весь интерфейс очков строится по принципам чистого Glassmorphism / Spatial UI (а не ретро-пикселей или устаревших кнопок).
   - **Аппаратные узкие места (Hardware Bottlenecks):**
     - То, из чего собраны очки, напрямую определяет физическую работу операционной системы:
       - **CPU (Процессор):** Отвечает за логику и скорость отклика. На слабом процессоре программы медленно открываются, долго считают и обрабатывают данные.
       - **GPU (Видеочип):** Отвечает за рендеринг окон и эффекты. На слабом GPU всё жутко лагает, рендер парящих окон дропает кадры, рывки при вращении головы. На хорошем GPU и слабом CPU — окна отрисовываются плавно, но сама система соображает медленно!
       - **RAM (Оперативная память):** Напрямую задает **лимит одновременно открытых сторонних приложений** (`*.vrapp`). При слабом ОЗУ можно запустить только 1-2 программы, для открытия новой придется закрывать старые.
         > 📌 **Исключение:** Ванильные экраны Minecraft (открепленный инвентарь, сундуки, верстаки, печи) **НЕ считаются программами** и не жрут слоты RAM! Их можно открывать и развешивать по миру сколько угодно!
       - **Storage Disk (Накопитель):** Определяет лимит количества установленных программ из магазина и лимит сохраненных файлов/заметок в файловой системе.
   - **Энергопотребление и батарея:**
     - Очки расходуют энергию при работе (HUD, рендеринг парящих окон, сетевой опрос Rednet).
     - В правом верхнем углу HUD отображается уровень заряда аккумулятора.
     - Зарядка: через специальную док-станцию (KVR Charging Stand), индукционную беспроводную зарядку или прямое подключение к FE/RF сетям (Create New Age, CC, Mekanism, Powah, TechReborn).
   - **Замена и прокачка компонентов (Моддинг шасси):**
     - На верстаке инженера (KVR Workbench) очки можно разобрать и заменить любой компонент на лету.

4. **Магазин приложений (App Store) и Внутриигровой Мессенджер с шарингом файлов:**
   - **KVR App Store:**
     - Каталог приложений, откуда можно устанавливать новые утилиты в пределах емкости диска.
   - **KVR Messenger & Быстрый обмен файлами (Zero Discord Needed):**
     - Встроенный P2P-мессенджер для игроков на сервере.
     - Больше не нужно сворачивать Minecraft в Discord, чтобы переслать координаты спавнера или базы!
     - **Сценарий из жизни:** Игрок нашел алмазную жилу в шахте -> открыл встроенный блокнот (`TextEdit`) -> нажал кнопку вставки текущих координат -> сохранил `coords.txt` -> открыл `KVR Messenger` и в 1 клик отправил файл другу.
     - Друг принимает файл в очках, открывает его, прикрепляет окно себе сбоку от плеча (в `Body Anchor`) и спокойно шурует по координатам, видя текст прямо в пространстве перед глазами!
   - **KVR Web Browser (CyberNet / Real Web View):**
     - Второе ключевое приложение из App Store после мессенджера — полноценный графический веб-браузер для серфинга в реальном интернете прямо в парящем окне очков!
     - **Архитектура WebView:** Отрисовка веб-страниц в offscreen OpenGL FBO текстуру на базе встраиваемого легковесного движка (Ultralight / CEF / системный WebView) и проецирование на плоскость 3D-окна очков.
     - **Интерактивность:** Полная трансляция мыши, скролла колесиком и клавиатуры в контекст страницы. Поддержка современного веба, скриптов, YouTube/Twitch видео и музыки.
     - **Интеграция с QuickJS:** Управление окном браузера через нативный API (`const browser = new WebView({ url: "https://..." }); window.mount(browser)`).
     - **Геймплейный стимул прокачки железа:** На базовых очках 1 тира (256 КБ диска и 1 окно) браузер не запустится; требует минимум 3–5 тир железа (высокий FPS, запас RAM и емкий аккумулятор). Позволяет читать гайды, Википедию, слушать музыку и залипать в сеть, не выходя из шахты и во время боссфайтов!

4. **Секретный легендарный артефакт: Хакерские очки (`HackGlasses` / Cyber Sniffer):**
   - **Условия получения и скрытность (Zero Creative Tab & No Craft):**
     - `HackGlasses` **не крафтятся** и **НЕ отображаются во вкладке Creative (скрыты из креатив-меню и JEI/REI/EMI)**!
     - Их существование в коде скрыто от глаз обычных игроков.
     - Единственные пути получения:
       1. Найти в **абсолютно любом сгенерированном сундуке мира** с шансом **0.5%** (1 к 200 сундукам).
       2. Прямая админская команда: `/give @p kvr:hackglasses`.
   - **Концепция шпионажа и MITM (Man-in-the-Middle):**
     - В обычных очках KVR все пространственные окна, HUD и виртуальные интерфейсы строго приватны и видны **только самому владельцу**.
     - Но для элиты кибер-подполья существует редкий секретный артефакт — **`HackGlasses` (Хакерские очки)**!
   - **Уникальные кибер-способности HackGlasses:**
     - **Рентген чужого HUD (Visual Spy & Screen Mirror):**
       - Когда хакер в `HackGlasses` смотрит на другого игрока в KVR-очках — он видит **абсолютно всё, что видит жертва**!
       - Все его парящие окна, открытые чаты, дашборды, код скриптов, уведомления и даже уровень заряда батареи отображаются в пространстве в реальном времени с зеленоватой сеткой взлома.
     - **Шпионаж за виртуальным миром (Virtual World Sniffing):**
       - Если жертва погрузилась в закрытый виртуальный мир / симуляцию внутри KVR — хакер видит фантомную проекцию этой симуляции и действия игрока прямо перед собой.
     - **Перехват кликов и инъекции:**
       - Возможность видеть луч Raycast прицела жертвы и даже тайно подсунуть клик по чужому окну или перехватить незашифрованный Rednet-пакет.

5. **Кинематика, планка захвата, ресайз и десктопные окна (Spatial Anchoring & Headless Desktop):**
   - **Нижняя планка захвата (Window Grab Bar / Handle):**
     - У каждого 3D-окна снизу парит тонкая эргономичная планка/ручка манипулятора (как в Apple Vision Pro и Meta Quest).
     - Навел прицел в режиме `Alt` на планку, зажал ЛКМ — и ты буквально держишь окно в руке (мышь XY, колёсико Z).
   - **Тактильный ресайз за края и пропорциональный жест масштабирования:**
     - Хватание за любой край/угол окна (рамка 6-8 px) позволяет свободно растягивать и сжимать окно в воздухе.
     - Пропорциональный жест масштабирования нацеливанием на окно позволяет плавно зумить его без искажения пропорций.
   - **Единая кнопка настроек (Шестерёнка):**
     - В правом нижнем углу любого окна (ваниль, JS-аппы, десктоп) находится шестерёнка с всплывающим меню:
       1. **Привязка:** `Body Anchor` (летит с телом при беге) / `World Anchor` (висит на блоке в мире).
       2. **Приватность:** `Public` (транслируется в мире другим игрокам, можно показать рабочий стол/браузер кентам!) / `Private` (видно только владельцу).
       3. **Блокировка (Lock):** защита от миссклика в бою/шахте — окно намертво фиксируется, клики проходят сквозь, жесты скрытия его не трогают. Разблокировка — кликом по шестерёнке.
       4. **Крестик `×`** в углу для быстрого закрытия.
   - **Свои Headless-окна хоста (Native Desktop Apps via Rust Smithay):**
     - Запуск реальных программ ПК (Firefox, плеер, консоль) внутри 3D-окон KVR без всплывающих окон на реальном мониторе/в WM.
     - Работает через встроенный headless Wayland-композитор (Smithay на Rust под Linux/niri и offscreen под Windows).
     - Нулевой оверхед через общую память (shm) + передача только измененных областей (Damage).
     - Автозахват ввода клавиатуры/мыши в режиме `Alt` при фокусе без потери фокуса самой игрой Minecraft.
     - Окно согласия (Consent GUI) в настройках мода перед скачиванием/запуском демона.
   - **Открепление любых ванильных экранов в 3D (Vanilla Screen Detachment / Pin to VR):**
     > ⚠️ **UI/UX Дисклеймер:** Вид всех кнопок, иконок и лейблов в концепте является ориентировочным примером. Окончательный профессиональный визуальный стиль, микро-копирайтинг и типографику прописывает Opus Thinking при финальной имплементации.
     - Любой ванильный экран Minecraft (инвентарь `E`, сундук, верстак, печь, алхимия, модовые контейнеры) можно в 1 клик перевести в Spatial 3D-окно!
     - Открыл инвентарь или сундук -> ткнул кнопку открепления в 3D -> плоский экран закрывается, а перед тобой в воздухе появляется постоянный парящий 3D-экран этого инвентаря/сундука!
     - Ты продолжаешь свободно бегать, драться, копать на `WASD`, а рядом висит твой инвентарь или открытый сундук, где можно на ходу перекладывать ресурсы и крафтить рукой через `Alt`! Больше никаких залоченных менюшек на весь монитор!

3. **Управление, Alt Toggle и Колесо жестов (Spatial Hand & Gesture Wheel):**
   - **Режим тумблера Alt (Toggle Mode, как CapsLock):**
     - Клавиша `Alt` работает **как тумблер (Toggle)**, а не зажатие:
       - Нажал `Alt` один раз — включился пространственный режим руки/прицела.
       - **Не блокирует взаимодействия:** Игрок полноценно ходит на `WASD`, бегает, прыгает, открывает инвентарь (`E`).
       - **Умный поворот камеры (Edge Pan & Deadzone):** В центре экрана рука и прицел свободно летают по окнам/миру. Если потянуть руку/прицел к любому краю экрана — камера плавно доворачивается в эту сторону (как в шутерах с deadzone или стратегиях)! Плюс при желании можно довернуть камеру стрелочками на клавиатуре.
       - **Визуальный курсор:** Дефолтный ванильный прицел Minecraft (крестик crosshair), который отрывается от центра и летает за рукой. При наведении на кнопки подсвечивается/масштабируется.
       - Нажал `Alt` ещё раз — крестик центрируется, и включается стандартное вращение камеры.
     - Работает **всегда, даже без очков** (для жестов, махания, флекса и РП-боёвки).
   - **Колесо системных жестов (Radial Gesture Wheel на Alt + ПКМ в шлеме):**
     - В режиме очков комбинация `Alt + ПКМ` вызывает круговое радиальное меню быстрого доступа с 5 ключевыми жестами:
       1. **Жест 1: `Вызов лаунчера приложений`** — распахивает главное меню со списком всех установленных в KVR OS программ (`*.vrapp`).
       2. **Жест 2: `Свернуть все приложения`** — мгновенно прячет все активные парящие 3D-окна в док-бар, очищая поле зрения.
       3. **Жест 3: `Свернуть текущее приложение`** — сворачивает окно в фокусе (на которое направлен курсор/луч руки).
       4. **Жест 4: `Войти в виртуальную среду (Virtual World Space)`** — развернуть виртуальное пространство (док-бар внизу с закрепленными приложениями, виртуальное зеркало с 3D-аватаром сзади, персональный кокон вокруг игрока при ходьбе по оверворлду).
       5. **Жест 5: `Создать дополнительное пространство под приложение`** — создать новый независимый парящий экран/монитор в 3D (как мониторы в Meta Quest / Oculus с Body/World anchor).
   - **3D-кинематика руки и левша:**
     - Мышь XY — направление руки в пространстве.
     - Колёсико мыши Z — глубина руки (от себя / к себе).
     - Поддержка ванильной настройки левши (`player.getMainArm()`): зеркалится на левую руку.
     - В руке отображается активный предмет (меч, топор, факел, еда).
     - **Физический РП-свинг:** удары по мобам пересечением хитбокса, рубка деревьев махами топора, юзание еды.
     - Положение руки синхронизируется по сети через легковесный пакет, чтобы все игроки видели живые движения.

4. **Интерьерное зеркало и Аватар:**
   - Парящее виртуальное зеркало с 3D-рендером скина и анимаций игрока.

## 2. Архитектура KVR OS, файловая система и пакеты (.vrapp)

Очки KVR работают под управлением полноценной микро-ОС (**KVR OS**):

1. **Виртуальная файловая система (VFS):**
   - У каждого экземпляра очков есть собственная изолированная файловая система (привязана к UUID предмета или профилю игрока).
   - Структура директорий KVR OS:
     - `/apps/` — установленные приложения (`*.vrapp` или распакованные директории).
     - `/system/` — системные модули UI, базовые темы, системные шрифты, настройки док-бара.
     - `/data/<app_id>/` — изолированное хранилище состояния и кэша приложений.
     - `/tmp/` — временные файлы и логи.

2. **Формат пакета приложения (.vrapp / .zip):**
   - Приложение пакуется в файл с расширением **`.vrapp`** (или обычный `.zip`).
   - По сути это чистый ZIP-архив (как APK в Android), внутри которого лежат:
     ```text
     myapp.vrapp
     ├── config.json       # Манифест: id, name, version, author, icon, window_opts
     ├── main.js           # Точка входа, эвенты, логика
     ├── components.js     # Визуальные компоненты UI
     ├── styles.js         # Стили и темы
     └── assets/           # Опциональные иконки, текстуры, звуки (.png, .ogg)
     ```
   - Движок KVR умеет:
     - На лету монтировать и читать `.vrapp` без полной ручной распаковки.
     - Либо работать напрямую с открытыми папками (`/apps/myapp/`) в режиме разработчика для мгновенного Hot Reload из VSCode.

3. **Предустановленные системные приложения KVR OS (Out of the box):**
   - «Из коробки» в чистых очках установлено **ровно две базовые программы**:
     1. **`App Market` (Магазин приложений):**
        - Главный шлюз экосистемы: каталог для поиска, скачивания и обновления любых сторонних приложений (`.vrapp`), кастомных виджетов и системных утилит прямо в игре в один клик.
     2. **`Calls` (Голосовые звонки / Телефон):**
        - Нативная звонилка для очков с интеграцией в популярные моды голосового чата (Simple Voice Chat, Plasmo Voice и др.).
        - Позволяет игрокам в очках буквально звонить друг другу тет-а-тет или собирать групповые конференции на любой дистанции (даже через измерения), отображая аватар собеседника, статус связи и громкость в HUD.
   - Все остальные приложения (проводник, блокнот, KAV-антивирус, калькуляторы, радары) игрок по желанию докачивает из `App Market` либо закидывает вручную в виде `.vrapp`!

4. **Менеджер пакетов, проводник и безопасность KVR OS:**
   - **KVR Package Manager (Installer):** Клик по файлу `.vrapp` в мире, в чате или передача через инвентарь/дискету устанавливает аппку в док-бар очков.
   - **Файловый менеджер (KVR Files):** Встроенный проводник для просмотра файлов, перемещения `.vrapp`, создания папок, удаления и редактирования прав.
   - **Права доступа и защита (Permissions & Sandbox):**
     - По умолчанию сторонние аппки живут в песочнице (User Space): им запрещено лазить в `/system/`, читать чужие `/data/<other_app>/`, спамить Rednet-пакетами или трогать сокеты без запроса разрешений (`network`, `fs_read_all`, `hardware_override`).
   - **Взлом прав и получение Superuser (KVR Root Exploit Chain):**
     - В KVR OS заложена скрытая интерактивная хакерская механика — квест/цепочка действий для взлома ядра очков и лутания **Superuser (Root)**!
     - Например:
       1. Потыкать 7 раз по номеру версии ядра в окне «О системе» (включает режим разработчика).
       2. Переполнить буфер терминала специальным скриптом/манифестом или подсунуть битый симлинк в `/tmp/`.
       3. Запустить цепочку перехвата прав (Privilege Escalation), обойдя защиту ядра.
     - **Что дает Superuser / Root:**
       - Доступ на прямую запись в `/system/` (кастомные биосы, свои системные хуки на рендер).
       - Разгон тактовой частоты эвентов (Overclocking HUD / 120 FPS UI).
       - Неограниченный доступ к памяти и шпионаж за чужими Rednet-каналами.
       - Установка неофициальных модов ядра прямо в игре!

4. **Система всплывающих тост-уведомлений (KVR Toast Engine):**
   - **Механика высирания тостов:**
     - В углу поля зрения (HUD) буквально вылетает (высирается) сочный анимированный тост-уведомление со звуковым кликом/бульканьем.
     - Универсальный вызов для системы и любых приложений:
       ```javascript
       kvr.toast({
         title: "Совет от очков",
         text: "Браток, ты чот апкакался! Возьми топор и не лашпедь!",
         icon: "axe",
         duration: 4000
       });
       ```
   - **Системные триггеры высирания тостов:**
     - **Копание не тем инструментом:** Долбишь рукой дерево при наличии топора в рюкзаке -> вылетает тост с напоминалкой (кулдаун 5 мин на тип блока).
     - **Добыча впустую:** Долбишь алмазы/золото неподходящей киркой или рукой -> тост: `⚠️ Руда сломается без дропа! Нужна железная кирка!`.
     - **Критическое HP (Low HP Alert):** Здоровье упало в нули (< 4 HP) под огнем -> тост высирается прямо перед глазами с вектором побега: `🚨 БЕГИ! Вектор отхода: на Север к свету! Скушай стейк!`.

5. **JS-Рантайм внутри очков (QuickJS Core + Custom KVR Bindings):**
   - В качестве движка утвержден **QuickJS** (микроскопический размер, холодный старт за миллисекунду, минимальный футпринт RAM).
   - В рантайм внедряется наш собственный кастомный API-слой (`kvr.*` bindings):
     - `kvr.fs` — чтение/запись файлов в `/data/` и песочницу аппки.
     - `kvr.window` — управление размерами, позицией, якорем (`body` / `world`), прозрачностью и заголовком.
     - `kvr.events` (`kvr.emit`, `kvr.on`, `kvr.off`) — локальная шина событий + шлюз в Rednet-модем ComputerCraft.
     - `kvr.ui` — регистрация и инстанцирование UI-виджетов (кнопки, слайдеры, канвас/текст, карточки).
     - `kvr.storage` — локальное Key-Value хранилище состояния аппки между перезапусками.
     - `kvr.timers` — микросекундные таймеры и анимационные тики (`setTimeout`, `setInterval`, `requestAnimationFrame`).

5. **Воркфлоу разработки (In-game vs PC IDE):**
   - **In-Game Notepad++ Editor:** Для быстрых фиксов, мелких макросов и тюнинга конфигов прямо на лету в очках.
   - **Внешний VSCode на ПК:** Для больших серьезных проектов какун открывает папку с приложениями (`.minecraft/kvr_apps/` или симлинк) в нормальном VSCode со всеми плагинами, линтерами и автокомплитом. Очки поддерживают Hot Reload (горячую перезагрузку скрипта по сохранению файла).
   - **Сборка пакета:** Команда в терминале очков `kvr pack myapp` мгновенно собирает папку в готовый `myapp.vrapp` для передачи корешам.

6. **Внутриигровой маркет приложений:**
   - Локальный репозиторий скриптов на сервере мира.
   - Игроки могут публиковать готовые дашборды и тулзы, другие — скачивать в один клик в док-бар очков.

## 3. Демо-приложение: KAV (Kasper AntiVirus / PonoScan 3000)

В качестве эталонного тестового приложения и бенчмарка возможностей движка создается рофельный антивирус **KAV**:

1. **Интерфейс:**
   - Стильное кибер-окно с зеленой кнопкой `[ 🛡️ ПОЛНОЕ СКАНИРОВАНИЕ СИСТЕМЫ ]`.
   - Прогресс-бар сканирования (0% -> 99%).
   - Бегущая строка проверки файлов: `mods/`, `saves/world/`, `dirom_brain.bin`, `trusiki_feroxa.zip`, `system32/ponos.dll`.
2. **Апкакивание и кульминация:**
   - На 99% шкала намертво стопорится.
   - Окно резко перекрашивается в кроваво-красный градиент опасности.
   - Включается анимация тряски окна (`shake`) и глитч-эффект текста.
   - Панель высыпает алерт: `КРИТИЧЕСКАЯ УГРОЗА! ОБНАРУЖЕНО 4,294,967,295 ПОНОСНЫХ ТРОЯНОВ!`.
   - Происходит «взрыв» окна: окно распахивает гигантский красный череп/BSoD прямо перед лицом игрока с кнопкой `[ ПОКАКАТЬ И ПЕРЕЗАГРУЗИТЬ ]`.
3. **Что тестирует в движке:**
   - Таймеры и интервалы QuickJS (`setInterval`, `setTimeout`).

   - Звуковые триггеры (сирена, треск, взрыв).
   - Работу всех 4 стартовых файлов (`config.json`, `main.js`, `components.js`, `styles.js`).

## 3. Взаимодействие с внешним миром (Event-Driven Rednet)

KVR полностью самодостаточен и не имеет зависимостей от индустриальных модов. Единственная внешняя модульная точка соприкосновения — **ComputerCraft: Tweaked** (через установку модема в слот очков).

Связь с механизмами мира происходит через стандартный брокер событий:

1. **Регистрация событий (Event Broker):**
   - Приложение в очках подписывается на сетевой топик / Rednet-протокол:
     ```js
     kvr.on("base:sensor_update", (data) => {
       gauge.setValue(data.value);
     });
     ```
2. **Отправка команд в мир:**
   - Нажатие кнопки в UI очков отправляет событие на стационарный компьютер:
     ```js
     kvr.emit("base:toggle_power", { state: true });
     ```
3. **Обработка в ComputerCraft (Lua):**
   - Домашний компьютер принимает событие и управляет редстоуном, дверями, лампами или любыми механизмами:
     ```lua
     rednet.open("back")
     while true do
       local id, msg = rednet.receive("kvr_events")
       if msg.type == "base:toggle_power" then
         redstone.setOutput("top", msg.state)
       end
     end
     ```

## 4. Стек технологий, версии Minecraft и мультилоадер

- **Целевые версии Minecraft:** **от 1.20 до 1.21.11+** (полный диапазон: поддержка 1.20.x, 1.21.x и будущих минорных апдейтов 1.21.11+).
- **Архитектура сборки (Мультилоадер):**
  - **Fabric + NeoForge** единая кроссплатформенная кодовая база на базе **Architectury Loom** (по аналогии с проверенным решением `experiments/khwrapper` для KasHub, где `:common` держит чистую бизнес-логику, а `:fabric` и `:neoforge` выступают тонкими мостами-адаптерами).
  - Для мультиверсионности (1.20 — 1.21.11+) к архитектуре Architectury подключается **Stonecutter**, который версионирует специфичные вызовы (Data Components vs NBT, различия маппингов рендера) без дублирования общего кода KVR OS.
  - Модульная структура репозитория:
    - `:common` — платформо-независимое ядро (KVR OS, QuickJS рантайм, VFS, эвенты, математика якорей, Raycast, Toast Engine).
    - `:fabric` — хуки и регистрация под Fabric Loader (1.20 — 1.21.11+).
    - `:neoforge` — хуки и регистрация под NeoForge (1.20.4 — 1.21.11+).
- **Рендеринг:** Оконный OpenGL/Vulkan пайплайн через хуки Fabric/NeoForge/Iris (полная совместимость с Sodium, Iris, Embeddium).
- **Скриптинг:** QuickJS (через JNI / Rust ffi) — микро-футпринт, холодный старт за 1 мс.
- **Интеграции:**
  - **Simple Voice Chat / Plasmo Voice API** (для встроенного приложения `Calls`).
  - **CC: Tweaked API** (опциональный сетевой шлюз Rednet при установке модема в слот очков).
  - **Curios API / Trinkets API** (аксессуарные слоты на NeoForge и Fabric).
  - Без сторонних модов очки работают полностью автономно как локальный HUD, плеер приложений и OS.
